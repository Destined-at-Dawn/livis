# Livis Plus

Windows x64 本地资料工作台，接收用户主动分享的 ZIP、TXT 和附件。Plus 免费免激活。

本仓库仅用于发布安装程序、使用说明和第三方声明，不公开开发总仓库或用户资料。

免费、免激活。安装程序与使用说明在同一 ZIP 中。实际程序首跑、安装、同版重装、0.5.3 公开版覆盖升级以及卸载保留外部资料已验证。Pro 暂未开放发行。

## 主要入口

- 微信主动分享：选择文件、归档原件、搜索文本、查看消息与附件。
- 本地知识与技术工作：保存资料、明确派发任务、绑定项目和模型、检查文件修改与差异。
- 日志与反馈：C 盘用户目录存储、元数据日志预览、勾选与导出。未配置接收端时明确保存为本地待提交。
- 联系作者：个人微信二维码；定制与企业、学校部署可沟通具体需求。作者网站：[lilanyuan.cn](https://lilanyuan.cn)。

## 版本边界

Plus 不包含个人微信/QQ 数据库读取、解密、密钥扫描或注入组件。Windows 原生分享菜单、macOS 接入、真实网站审查、联网反馈送达和 Pro 发行仍按对应验收状态开放。

默认不用模型也能导入、保存和搜索。可以配置本地兼容模型接口，或自行选择云服务；云服务与外部连接器不是离线功能。本地存储与完全离线、全链路私有化是不同验收层级。
