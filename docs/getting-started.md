# 开始使用 Livis

## 下载与安装

在 [Releases](https://github.com/Destined-at-Dawn/livis/releases) 下载 Windows x64 ZIP。解压后运行安装程序，按提示选择安装目录，再打开 Livis Plus。

Plus 免费，不需要激活码。不使用 AI 时，选择暂时不用模型即可。

当前 `1.0.0 r1` 为预览版。安装、首跑、同版重装、0.5.3 公开版覆盖升级与卸载保留外部资料已检查。真实微信导出兼容性还在补测，不能把示例文件导入成功等同于所有真实导出都兼容。

## 导入一份聊天记录

1. 先准备自己导出的 ZIP、TXT 或附件。
2. 打开微信主动分享，选择文件。
3. 点击导入所选文件，等待批次出现在列表中。
4. 输入关键词查找内容，打开批次查看消息、附件或下载原件。

没有选择文件时，程序不会导入整个文件夹。同一个原文件再次导入会复用已有批次。未识别的聊天文本仍保留原件，不会自动编出发言人或时间。

想先看文件长什么样，可以使用仓库中的 [示例文件](../examples/)。张三、李四和群名均为虚构。

## 模型与数据

导入、保存和搜索可以不使用模型。如果需要 AI，在设置中配置自己的服务，刷新模型列表，再选择本机或供应商实际提供的模型。

已启动的本地 OpenAI 兼容服务可以连接，例如 `http://127.0.0.1:11434/v1`。Livis 不附带大模型，不会自动下载模型。可用名称以服务返回的模型列表为准。

选择云模型处理内容时，请求会发送到该服务。需要离线处理时，使用本机服务，不使用云模型和外部连接器。这里的本地存储说明不是对所有网络功能的离线承诺。

文件默认放在 `%LOCALAPPDATA%\Livis\data`。旧公开版可能沿用 `%LOCALAPPDATA%\LivisPublic\data`，另选目录的用户以实际设置为准。详见 [文件与备份](files-and-data.md)。

## 日志与反馈

打开日志与反馈，先预览，再勾选要导出的诊断文件。导出的反馈包保存在 `%LOCALAPPDATA%\Livis\feedback`，当前状态是本地待提交，需要你自行交给作者。

诊断日志包含版本、动作、错误类型和计数等信息，不加入聊天正文、附件内容、Token 或密码。公开反馈只需描述问题，不要上传你的聊天记录。

## 更新与卸载

当前更新方式是从 Releases 下载安装程序。在线自动更新还未接通。已经检查的覆盖升级范围是 0.5.3 公开版，不包括 0.5.6 完整内测版。

卸载程序会移除应用；外部资料目录在本轮检查中保留。换电脑前，请先备份实际资料目录，而不是只复制安装文件夹。

## 当前还没接通的入口

Windows 系统分享菜单、macOS、网站审查、反馈自动送达和在线自动更新仍未开放完整流程。当前可用的主动分享入口是应用内的文件选择器。Pro 暂未开放下载。

## 联系作者

在应用中打开联系作者，查看个人微信二维码。定制版、企业和学校安装服务也可以从 [lilanyuan.cn](https://lilanyuan.cn) 联系。

## 安装与启动遇到问题

### Windows 弹出“已保护你的电脑”

安装程序暂未做代码签名，Windows SmartScreen 会提示“Microsoft Defender SmartScreen 阻止了无法识别的应用启动”，发布者显示“发布者未知”。这是对所有未签名新程序的通用提示，不说明文件有问题，但放行前要先确认文件来源。

1. 只从官网下载页或本仓库的 Releases 取得文件，用 `Get-FileHash .\下载的文件名.zip -Algorithm SHA256` 算出 SHA-256，和发行页一致再继续。不一致就删除重下。
2. 在提示里点正文下方的“更多信息”。一开始通常只有“不运行”一个按钮，点过“更多信息”后才会出现“仍要运行”。
3. 核对显示出的应用名是 Livis Plus 的安装程序，点“仍要运行”。出现“用户账户控制”时点“是”，照向导安装。
4. 点了“更多信息”仍然没有“仍要运行”：右键下载的 ZIP → 属性 → 常规页底部勾选“解除锁定” → 确定，再解压运行；也可以对安装程序执行 `Unblock-File -Path .\安装程序文件名.exe`。ZIP 要在解压之前解除。
5. 标题是“智能应用控制已阻止此应用”（Windows 11 智能应用控制）：它会直接拦下所有未签名程序，没有“仍要运行”。只能在“Windows 安全中心 → 应用和浏览器控制 → 智能应用控制设置”中关闭后安装；按微软说明，多数版本关闭后不能直接再打开，不确定就等签名版。学校或公司电脑被管理员策略限制时，请联系管理员，不要自行绕过。

不要为了装软件关闭 Windows Defender 或 SmartScreen 的总开关，只对这一个文件放行。校验值对不上或应用名与下载的不一致，就选“不运行”。

### 第一次启动很慢，或提示“后台服务启动超时”

1.1.1 起，窗口会先出现并显示“正在启动 Livis…”和已等待秒数，等待上限是 4 分钟。电脑较慢、安装在机械硬盘、或杀毒软件正在扫描安装目录时，第一次启动可能需要 1～3 分钟。

1. 只双击一次，不要重复双击。
2. 已经弹出超时提示：在任务管理器结束所有 Livis Plus，以及 Livis 自带的 python.exe（路径在安装目录的 resources\python 下），再双击一次，耐心等 2～4 分钟。
3. 仍然很慢：把安装目录加入 Windows Defender 的“排除项”，或把 Livis 装到 C 盘固态硬盘。
4. 仍然失败：把 `%LOCALAPPDATA%\Livis\logs\livis-main.jsonl` 交给作者；日志里的 `ready_ms` 是后台就绪耗时。

1.1.0 及更早版本启动时要把约 1.6 万个程序文件逐个算校验值，慢的电脑会超过 120 秒被判失败，失败后再双击还会没有反应。1.1.1 已改为启动只做快速检查、逐文件校验放到后台，请升级。
