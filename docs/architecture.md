# Livis 的组件与数据流

本文对应当前 Windows Plus 预览版，不把计划中的功能画成已实现。

## 导入与查找

你选择 ZIP、TXT 或附件 → Livis 桌面界面 → 本机后端 → Inbox 原文件与解析结果 → 本机 SQLite 资料库 → 搜索、查看消息与原件。

程序处理你选择的文件，不读取微信或 QQ 数据库。文件清单、解析结果和批次状态分别保存为 manifest.json、derived.json、state.json。ZIP 的解包内容保留相应目录名称，重复文件复用现有批次。

## 可选模型调用

导入、保存和搜索不需要 AI。选择 AI 操作时，应用调用你配置的模型服务：

- 本机模型：请求本机兼容服务，由你安装模型与运行服务；不随 Livis 安装包提供。
- 云模型：请求你配置的云 API，所选内容会发送给该服务。

资料本机存储和模型请求是不同的边界，不能把前者当作所有网络行为都关闭的证明。

## 运行组件

Windows 桌面程序提供界面与启动管理，随包运行时承载本机后端，Inbox 保留原件与批次结果，SQLite 保存资料库。诊断日志与导出的反馈包位于用户目录。

查看[实际文件目录](files-and-data.md)与[模型配置](getting-started.md#模型与数据)。
