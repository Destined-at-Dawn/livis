# Livis 0.6.6 数据流与边界

Livis 是 Windows x64 本地工作台。安装包、用户资料和公开仓库各自有独立边界。

## 组件

- **桌面入口**：负责启动本地工作台和设置。
- **本地资料层**：保存用户主动导入的聊天记录、附件、索引和原件。
- **Agent Desk**：在白名单目录内读取 Claude Code、Codex 和 Pi 的本机会话 JSONL，提供会话检索和详情查看。
- **插件层**：聊天读取、同步和其他扩展能力通过签名插件包与授权状态控制。
- **模型连接**：用户主动选择模型服务后，相关内容才会按配置发送到本机服务或云服务。

## 数据边界

导入、保存和本地搜索可以不使用模型。使用云模型时，发送范围由用户当前操作和模型配置决定。Livis 不把用户聊天库、授权码、API Key 或密码写进公开仓库。

Agent Desk 只读取白名单目录中的会话文件。它不会替用户向 Claude、Codex、Pi 或聊天平台发送消息，也不会把会话自动上传到 GitHub。

## 授权边界

主程序默认直接进入。旧版 beta activation、legacy 文件和旧命名的 license 文件不会被读取、迁移或刷新。新版授权状态使用 v2 文件命名空间。

付费插件独立判断授权状态。安装主程序不等于自动获得聊天同步或其他插件能力。

## 公开仓库边界

本仓库提供下载入口、Release 元数据、校验材料、使用说明、示例和问题反馈。核心应用源码、Git 元数据、用户文件、开发环境和本机会话不在仓库中。
